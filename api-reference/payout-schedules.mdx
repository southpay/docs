<Warning>
  All endpoints require authentication. See [Authentication](/authentication).
</Warning>

Base URL: `https://api.southpay.io/api/v2`

A payout schedule defines, for one asset, **how often** the store's accumulated balance is paid out and **where** the proceeds go. The destination is either:

- A **fiat payout detail** - funds are off-ramped and arrive as fiat in your bank account.
- A **crypto payout detail** - funds are sent on-chain to an external wallet you control.

Schedules are evaluated continuously. If a schedule's `next_payout_at` has passed and the accrued balance meets `minimum_fiat_cents`, a payout is created automatically.

## Get a schedule

Returns the schedule with all payouts it has produced.

```bash
GET /payout_schedules/:id
```

---

## Create a schedule

<CodeGroup>
```bash Request
POST /payout_schedules
Authorization: Bearer <API_KEY>
Content-Type: application/json

{
  "payout_schedule": {
    "asset_id": "ETH_USDC",
    "frequency": "weekly",
    "minimum_fiat_cents": 50000,
    "minimum_fiat_currency": "USD",
    "fiat_payout_detail_id": "01HX..."
  }
}
```
</CodeGroup>

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `asset_id` | string | Yes | Asset whose balance this schedule drains (e.g. `ETH_USDC`). |
| `frequency` | string | Yes | `daily`, `weekly`, `monthly`. |
| `minimum_fiat_cents` | integer | Yes | Minimum balance in fiat cents required to trigger a payout. |
| `minimum_fiat_currency` | string | No | ISO 4217 fiat code for the minimum threshold. Defaults to `USD`. |
| `fiat_payout_detail_id` | string | One of | Send proceeds as fiat to this bank account. |
| `crypto_payout_detail_id` | string | One of | Send proceeds on-chain to this address. |
| `swap_target_asset_id` | string | No | For crypto destinations: auto-swap the source asset into this target before payout. |
| `next_payout_at` | ISO 8601 | No | First scheduled run. Defaults to end of the current day. |

Exactly one of `fiat_payout_detail_id` or `crypto_payout_detail_id` must be set.

---

## Update a schedule

```bash
PATCH /payout_schedules/:id
```

Same fields as create, except `asset_id` cannot be changed. Pass `active: false` to pause without deleting.

---

## Delete a schedule

```bash
DELETE /payout_schedules/:id
```

Marks the schedule inactive. History (existing payouts) is preserved.
