title: "Quickstart"
description: "Mint a token, create two accounts, post a balanced transaction, and read the balance."
---

This walkthrough takes you from credentials to a posted transaction in four `curl` calls. Each call matches the [API reference](/ledger/api-reference/introduction).

<Info>
  The base URL is `https://ledger.southpay.io/api`. OAuth lives at `/oauth/token`; the ledger resources live under `/v1`.
</Info>

## 1. Get your client credentials

Create an OAuth client from the dashboard, or use one seeded for you in development. A client has a `client_id`, a `client_secret` (shown once), a mode (`test` or `live`), and a set of granted scopes. Read operations need `ledger:read`; writes need `ledger:write`.

```bash
export CLIENT_ID="client_xxxxxxxxxxxxxxxxxxxxxxxx"
export CLIENT_SECRET="sk_test_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

## 2. Mint an access token

Exchange your credentials for a short-lived token using the `client_credentials` grant. Send the credentials as HTTP Basic auth.

```bash
curl -X POST https://ledger.southpay.io/oauth/token \
  -u "$CLIENT_ID:$CLIENT_SECRET" \
  -d 'grant_type=client_credentials&scope=ledger:read ledger:write'
```

The response is an HS256 JWT valid for one hour:

```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "Bearer",
  "expires_in": 3600,
  "scope": "ledger:read ledger:write"
}
```

Save the token for the calls below:

```bash
export TOKEN="eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
```

The token carries your tenant, mode, and scopes. There is no `?test=` flag: the client's mode decides whether you touch test or live data. See [Authentication](/ledger/authentication) for the full flow.

## 3. Create two accounts

An account is a named bucket of value in one currency. You choose the `id`. Create one asset account and one revenue account, both in `USD`.

```bash
curl -X POST https://ledger.southpay.io/api/v1/accounts \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"id":"cash:usd","name":"Cash","type":"asset","currency":"USD"}'

curl -X POST https://ledger.southpay.io/api/v1/accounts \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"id":"revenue:subscriptions","name":"Subscriptions","type":"revenue","currency":"USD"}'
```

Each call returns the created account inside the standard envelope:

```json
{
  "data": {
    "object": "account",
    "id": "cash:usd",
    "name": "Cash",
    "type": "asset",
    "currency": "USD",
    "currency_decimals": 2,
    "currency_kind": "fiat",
    "metadata": {},
    "created_at": "2026-05-14T10:23:45.123456Z"
  },
  "livemode": false,
  "request_id": "req_3LhM8XKx9q4hQv"
}
```

## 4. Post a balanced transaction

A transaction is a set of postings that balance per currency. Move 10.00 USD (`1000` minor units) from cash into revenue. Writes require an `Idempotency-Key` so retries never double-post.

```bash
curl -X POST https://ledger.southpay.io/api/v1/transactions \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: invoice_001" \
  -d '{"postings":[
        {"account":"cash:usd","amount":1000,"currency":"USD","direction":"debit"},
        {"account":"revenue:subscriptions","amount":1000,"currency":"USD","direction":"credit"}
      ]}'
```

The response includes the transaction and its postings:

```json
{
  "object": "transaction",
  "id": "3061ec4e-c959-49ba-a0f6-99186a7bd5d8",
  "idempotency_key": "invoice_001",
  "reverses": null,
  "reversed_by": null,
  "metadata": {},
  "postings": [
    { "object": "posting", "account": "cash:usd", "amount": 1000, "currency": "USD", "direction": "debit", "pending": false },
    { "object": "posting", "account": "revenue:subscriptions", "amount": 1000, "currency": "USD", "direction": "credit", "pending": false }
  ],
  "created_at": "2026-05-14T15:53:31.291591Z"
}
```

Replaying the same `Idempotency-Key` returns this same transaction with a `200` instead of creating a new one. To validate a transaction without writing it, add `?dry_run=true` and omit the idempotency key.

## 5. Read the balance

Read the cash account's balance:

```bash
curl https://ledger.southpay.io/api/v1/accounts/cash:usd/balance \
  -H "Authorization: Bearer $TOKEN"
```

You can read a historical balance by passing `?at=<ISO 8601 timestamp>`, which computes the balance from each posting's `value_date`. See [Core concepts](/ledger/concepts#value-date-semantics).
